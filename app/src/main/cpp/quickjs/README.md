# QuickJS 2026-06-04

These unmodified files are from the [official QuickJS release archive](https://bellard.org/quickjs/quickjs-2026-06-04.tar.xz).

The archive has SHA-256 `b376e839b322978313d929fd20663b11ba58b75df5a46c126dd19ea2fa70ad2a`.

The directory contains the sources and headers required to build the ECMAScript
engine, including its generated Unicode tables, plus the upstream `VERSION`
and `LICENSE`. CMake builds those sources offline. The QuickJS command-line
tools and `quickjs-libc` host bindings are excluded.
