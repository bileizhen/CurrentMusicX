# CurrentMusic Native 隐私说明

## 服务器连接

应用连接可修改的 CurrentMusic Server，发送登录信息、搜索词、歌曲 ID 和音质选项。默认地址为 https://music.20110208.xyz/cm。HTTP 连接不加密。账户数据由所选服务器保存。点赞、歌单、最近播放与推荐从所选服务器获取，歌单的创建、修改及增删曲目由用户操作触发。

## 本地数据

Token 由 Android Keystore AES-GCM 加密并存于不备份的私有目录。DataStore 保存服务器、外观与账户显示信息；Room 保存搜索历史、歌曲元数据、歌词及队列。播放直链不持久化。退出登录清除会话，临时离线不会删除 Token。

## 播放与网络

音频、MV 视频和图片从服务器返回的 CDN 地址加载。Media3 前台服务用于后台、通知栏、锁屏和蓝牙控制，不使用麦克风。登录状态下，歌曲开始实际播放时向服务器记录歌曲；继续播放时周期上报实际收听毫秒，暂停和缓冲时间不计入，拖动进度不会当作收听时长。MV 不计入歌曲播放记录。观看 MV 时暂停音乐，退出后恢复原音乐队列，等待用户继续播放。

## 日志与诊断

容量受限的运行与崩溃日志对凭据统一脱敏，不参与备份。登录提交设备型号和 app 平台标识。主动导出的诊断包含应用版本、Android 版本和设备型号。

## 更新

检查更新连接 GitHub Releases；仅选择 CurrentMusic 原生安装包。下载及安装由用户操作。

## 后续功能

当前版本不实现独立歌曲收藏、网易云绑定、DLNA 或局域网扫描，后续实现前会更新隐私说明。
