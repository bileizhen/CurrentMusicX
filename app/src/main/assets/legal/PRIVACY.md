# CurrentMusic Native 隐私说明

## 服务器连接

应用连接可修改的 CurrentMusic Server，发送登录信息、搜索词、歌曲 ID 和音质选项。默认地址为 https://music.20110208.xyz/cm。HTTP 连接不加密。账户数据由所选服务器保存。点赞、歌单、最近播放与推荐从所选服务器获取，歌单的创建、修改及增删曲目由用户操作触发。

## 本地数据

Token 由 Android Keystore AES-GCM 加密并存于不备份的私有目录；多个账号按服务器与账户 ID 分别保存加密凭据，旧会话自动迁入。DataStore 仅保存服务器、外观与账户显示信息；Room 保存搜索历史、歌曲元数据、歌词及队列。密码和验证码不持久化，播放直链不持久化。退出登录清除当前账号凭据，其他保存的账号保留；移除保存的账号仅清理本机凭据。临时离线不会删除 Token。

## 用户资料与网易云绑定

资料、听歌统计、用户广场和挂件目录由所选服务器提供。资料修改、挂件设置和头像上传由用户触发。头像通过系统照片选择器选取，在内存中缩小后上传，不请求读取整个相册的权限。公开主页和用户广场请求不携带登录 Token。

注册验证码、网易云手机验证码由用户点击后发送；手机号、区号和验证码经所选服务器处理。扫码绑定使用本机生成的二维码，仅在绑定页面前台轮询授权状态，离开页面或切换账号后停止。网易云 Cookie 由服务器管理，原生客户端不保存。绑定成功自动同步歌单，手动同步可续传未完成的歌单；解绑保留已导入歌单快照。

## 播放与网络

音频、MV 视频和图片从服务器返回的 CDN 地址加载。Media3 前台服务用于后台、通知栏、锁屏和蓝牙控制，不使用麦克风。登录状态下，歌曲开始实际播放时向服务器记录歌曲；继续播放时周期上报实际收听毫秒，暂停和缓冲时间不计入，拖动进度不会当作收听时长。MV 不计入歌曲播放记录。观看 MV 时暂停音乐，退出后恢复原音乐队列，等待用户继续播放。

## 日志与诊断

容量受限的运行与崩溃日志对凭据统一脱敏，不参与备份。登录提交设备型号和 app 平台标识。主动导出的诊断包含应用版本、Android 版本和设备型号。

## 更新

检查更新连接 GitHub Releases；仅选择 CurrentMusic 原生安装包。下载及安装由用户操作。

## 一起听与局域网投屏

一起听向所选服务器发送房间名称、密码、房间号、点歌信息及管理操作，并通过带授权头的 SSE 接收房间事件。房间密码、播放直链与事件序号仅在当前会话内存中保存，不写入日志或数据库。退出房间或切换账号会取消订阅与心跳，恢复本地队列并保持暂停。

DLNA 仅在点击搜索设备后使用 Wi-Fi 组播扫描局域网，扫描结束或取消后释放组播锁。选择设备并确认投屏后，向该设备发送歌曲元数据、播放地址及播放、进度和音量指令，不发送 CurrentMusic 账户凭据。投屏时手机暂停发声；结束投屏后恢复本地队列，等待用户继续播放。设备及播放地址不持久化。
